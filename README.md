K-Sentry is our earlier research project on formally verified, tamper-evident kernel telemetry.
TraceLock is a follow-up research effort that builds on the foundations developed in K-Sentry.
TraceLock extends the work toward trace integrity, ordering, and tamper detection.
The TraceLock work introduces new experiments, implementation components, and analysis beyond the original K-Sentry project.
The TraceLock paper is the continuation of the K-Sentry research, rather than a rebranding of the original work.
K-Sentry provides the research foundation, while TraceLock develops the next stage of the approach for the workshop/conference paper.
